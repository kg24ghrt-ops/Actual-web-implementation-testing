Photorealistic notebook paper — A4 DIN 476

This is a photorealistic lined notebook page rendered at true DIN 476 dimensions using the notebook-paper-css library. The paper texture is a scanned image of real notebook paper.

Click on any line to start typing handwritten text. Use the Write button or press W to toggle handwriting mode.
